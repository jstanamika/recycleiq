# RecycleIQ

**Scan. Sort. Sustain.**

RecycleIQ is a privacy-friendly Progressive Web App for the school/college project **“Smarter Recycling: Using AI to Identify Recyclable and Non-Recyclable Waste.”** It helps people identify everyday waste with a camera, photo upload, or manual search, then explains the correct next step.

## Features

- On-device waste scanner with camera, upload, drag-and-drop, MobileNet assistance, confidence, manual correction, bin guidance, and disposal tips.
- Manual search index with 80+ common items, materials, preparation steps, recyclability, and environmental facts.
- Nine-category waste guide with configurable bin colours.
- Local dashboard with scan history, eco-score, weekly activity, streaks, badges, and estimated CO2 savings.
- Learn section with practical explainers and a 10-question quiz.
- About page with the Image → Preprocessing → Neural Network → Prediction → Category → Disposal advice pipeline.
- English, Hindi, and Punjabi translation scaffold, theme toggle, text-size setting, camera help, and clear-history control.
- Installable PWA with service-worker caching and iOS/Android/desktop install guidance.
